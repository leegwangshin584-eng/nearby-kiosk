내 주변 무인민원발급기 찾기 — 모바일 우선 시험판
1. index.html을 열면 화면을 미리 볼 수 있습니다.
2. 위치 확인은 HTTPS로 공개한 사이트 또는 localhost에서만 정상 작동합니다. 파일을 더블클릭한 로컬 환경에서는 브라우저에 따라 차단될 수 있습니다.
3. 실제 발급기 데이터는 아직 없습니다. 공식 자료 검증 후 script.js의 kiosks 배열에 입력하거나 데이터 연결 기능을 개발해야 합니다.
4. 일요일/공휴일 운영 여부가 확인되지 않은 장소는 해당 조건 검색에서 제외합니다.
5. 검색 거리 표시는 도로 주행 거리가 아닌 직선거리입니다.
